# پلتفرم آموزش آکادمیک پزشکی

## اگر سایت هنوز README نشان می‌دهد، این کار را دقیق انجام بده:

### روش ۱ (پیشنهادی — بدون Actions)

1. برو: https://github.com/hamedsony60-a11y/medical-education-platform/settings/pages
2. **Source** → **Deploy from a branch**
3. Branch: **main**
4. Folder: **/docs**
5. Save
6. ۲ دقیقه صبر کن، بعد با Ctrl+Shift+R رفرش کن:

https://hamedsony60-a11y.github.io/medical-education-platform/

### روش ۲ (با Actions)

1. Settings → Pages → Source → **GitHub Actions**
2. برو تب **Actions** → workflow را Run کن (یا صبر کن تا خودکار اجرا شود)
3. وقتی سبز شد، همان آدرس را باز کن
