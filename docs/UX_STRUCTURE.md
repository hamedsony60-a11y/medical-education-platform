# ساختار UX پلتفرم آموزش پزشکی

## جریان‌های اصلی کاربر

### ۱. آزمون آنلاین
- لیست آزمون‌ها → فیلتر تخصص → جزئیات → شروع آزمون → پاسخ‌دهی → نتیجه و گزارش
- پنل مدرس: ساخت آزمون → افزودن سوال → انتشار → مشاهده آمار

### ۲. ویدیوی آموزشی
- کاتالوگ → فیلتر دسته‌بندی → صفحه ویدیو (پلیر + توضیحات) → پیشرفت تماشا
- آپلود: انتخاب فایل → متادیتا → انتشار

### ۳. فایل صوتی
- کتابخانه → پخش در صفحه یا پلیر شناور → پلی‌لیست

### ۴. فروشگاه
- کتاب چاپی: کاتالوگ → جزئیات → سبد → پرداخت → پیگیری ارسال
- کتاب الکترونیک: کاتالوگ → پیش‌نمایش → خرید → دانلود

### ۵. سمینار
- لیست/تقویم → جزئیات → ثبت‌نام → یادآوری

### ۶. داشبورد
- پیشرفت یادگیری، آزمون‌های اخیر، خریدها، رویدادها

## اصول UI/UX پیشنهادی

- RTL کامل و فونت فارسی (Vazirmatn)
- دسترسی‌پذیری (کنتراست، فوکوس، aria)
- موبایل‌فرست
- کامپوننت‌های یکپارچه (دکمه، کارت، فرم، جدول)
- حالت خالی و لودینگ مشخص برای هر بخش
